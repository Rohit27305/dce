## 🚀 Part 2: Demo Repository Setup
*For the judges to test your project, follow these steps to prepare your demo repo.*

### 1. The Repo
I recommend using the **DCE Engine Core** itself as a demo, or create a simple repo like [https://github.com/Rohit27305/dce-demo](https://github.com/Rohit27305/dce-demo).

### 2. Showcase Features
*   **Manual Sync**: Show them the 'Sync Protocol' button in action.
*   **PR Magic**: Show a PR generated by `@DCE-AI` with the branded header and impact summary.
*   **Private Repo Badge**: Demonstrate that DCE respects privacy while maintaining consistency.

### 3. Demo Data
Ensure the judges see:
*   A **Trust Score** above 80%.
*   At least **2-3 Sync Events** in the history.
*   The **Real-time Flow** metrics moving on the dashboard.

## 📽️ Part 3: Recording Instructions
1.  **Screen Recording**: Use OBS or Loom.
2.  **Zoom in**: Keep the text large when showing the dashboard (browser zoom 110%).
3.  **Show the PR**: Judges LOVE seeing actual GitHub Pull Requests. Make sure to click the "REVIEW PR" link live.
4.  **Tone**: Professional, energetic, and focused on the *Impact*.
